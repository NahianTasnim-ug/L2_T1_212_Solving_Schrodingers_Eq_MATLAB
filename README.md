# L2_T1_212_Solving_Schrodingers_Eq_MATLAB
Level 2 Term 1 project in BUET undergrad by Nahian Tasnim and Ilias Ahmad. 
This project was done in MATALB as a part of Numerical Technique Laboratory Course, supervised by Sadman Sakib Ahbab.


Its main objective was to calculate the Eigen state energy for a particle confined in finite potential well 
and to compare between finite and infinite potential well.
